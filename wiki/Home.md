# הרמת סביבת הפיתוח והרצת המערכת

מסמך זה מתאר כיצד לקמפל ולהריץ את כל השרתים והאפליקציות של המערכת יחד בעזרת `docker-compose`. המערכת משלבת שרת Express ב-NodeJS, מנוע המלצות ב-C++ ואפליקציית React.

## דרישות מוקדמות
* **Docker Desktop**: מותקן ופועל.

> [!CAUTION]
> **הדליקו קודם את ה-Docker!**
> לפני הרצת פקודות ה-`docker-compose`, חובה לפתוח את תוכנת **Docker Desktop** במחשב ולוודא שהיא פועלת (האייקון שלה מופיע למטה בשורת המשימות והסטטוס ירוק). אם הדוקר לא פועל ברקע, הפקודות ייכשלו.
## הרצת המערכת בעזרת Docker Compose

תהליך זה יבנה את תמונות ה-Docker, יקמפל את קוד ה-C++, יתקין את חבילות ה-NodeJS וירים את כל השרתים (Web, Server, Mongo, Client).

### 1. הרצת הקונטיינרים
פתחו מסוף (Terminal) בתיקייה הראשית של הפרויקט והריצו את הפקודה הבאה על מנת לבנות את התמונות ולהרים את כל הסביבה בבת אחת:
```bash
docker-compose up --build
```
פעולה זו תקמפל את קוד ה-C++, תוריד את תמונות הבסיס, תתקין את כל התלויות ותריץ את הרכיבים הבאים:
- `server` - שרת ההמלצות ב-C++ המאזין לפורט פנימי `5555`.
- `web` - שרת ה-NodeJS המריץ את ממשק ה-React וה-API, חשוף בפורט `1234`.
- `mongo` - בסיס הנתונים של MongoDB.
- `client` - מסוף Python אינטראקטיבי.

### 2. שחרור החיבור לשרת ה-C++
שרת ההמלצות C++ מקבל רק חיבור אחד בו-זמנית. קונטיינר ה-`client` תופס את החיבור הזה כברירת מחדל. כדי לאפשר לשרת ה-Web (אפליקציית React) להתחבר ולשלוח נתוני המלצות, יש לעצור את קונטיינר ה-client:
```bash
docker compose stop client
```

### 3. גישה לאפליקציה
כעת, פתחו דפדפן והיכנסו לכתובת:
```
http://localhost:1234
```
המערכת מוכנה לשימוש!

### 4. סיום וכיבוי
כדי לעצור את הריצה ולמחוק את הקונטיינרים מהזיכרון (כולל רשתות), הריצו:
```bash
docker compose down
```
