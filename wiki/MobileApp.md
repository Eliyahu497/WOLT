# אפליקציית המובייל (Expo)

פרויקט זה כולל גם אפליקציית מובייל עבור הלקוחות, אשר נבנתה באמצעות [Expo](https://expo.dev/) (React Native). האפליקציה מתחברת לאותו שרת Express (NodeJS) כמו ממשק ה-Web.

## דרישות מוקדמות
* **NodeJS** מותקן על המחשב.
* אפליקציית **Expo Go** מותקנת על מכשיר הטלפון הנייד (Android/iOS) או לחלופין אמולטור (Android Studio / Xcode Simulator) מותקן במחשב.

## הרצת האפליקציה

> [!IMPORTANT]
> **שלב 0: הפעלת שרתי הבקאנד**
> לפני שאתם מריצים את אפליקציית המובייל, עליכם לוודא שהשרת של המערכת כבר רץ. חזרו לתיקייה הראשית של הפרויקט והריצו את הסביבה בעזרת:
> ```bash
> docker-compose up --build
> ```
> רק לאחר מכן המשיכו לשלבים הבאים כדי להריץ את האפליקציה.

1. **התקנת תלויות (Dependencies):**
   פתחו מסוף (Terminal) בתיקיית `mobile` הממוקמת בתוך התיקייה הראשית של הפרויקט (ניתן לעשות זאת על ידי `cd mobile`), והריצו:
   ```bash
   npm install
   ```

2. **הפעלת שרת הפיתוח של Expo:**
   לאחר התקנת התלויות, באותו מסוף הריצו את הפקודה:
   ```bash
   npm start
   ```

3. **פתיחת האפליקציה:**
   * במסוף יופיע קוד QR. סרקו אותו באמצעות אפליקציית המצלמה (ב-iOS) או ישירות באפליקציית Expo Go (ב-Android).
   * ניתן גם להקיש `a` במסוף כדי לפתוח באמולטור אנדרואיד, או `i` עבור סימולטור iOS (אם מותקנים).

## התחברות ושימוש
האפליקציה מאפשרת ללקוחות לבצע את כל פעולות הליבה: התחברות לחשבון, צפייה במסעדות, צפייה במנות, חיפוש, והוספת מוצרים לעגלת הקניות.

## הגדרת כתובת IP (חשוב מאוד להרצה על מכשיר פיזי!)
מאחר שהאפליקציה רצה על המכשיר הנייד שלכם (דרך Expo Go), היא צריכה לדעת כיצד לפנות לשרת ה-NodeJS שרץ על המחשב. המילה `localhost` מהטלפון תפנה לטלפון עצמו ולכן הבקשות ייכשלו.

כדי לתקן זאת, עליכם להחליף את כתובת ה-IP בקובץ ה-API שבאפליקציה:
1. פתחו את המסוף (Terminal) במחשב שלכם, והקלידו `ipconfig` (ב-Windows) או `ifconfig` (ב-Mac/Linux) כדי למצוא את כתובת ה-IP הפנימית שלכם (לרוב מתחילה ב-`192.168` או `10.0`).
2. פתחו את הקובץ `mobile/services/api.js` בעורך הקוד שלכם.
3. בשורות הראשונות של הקובץ מוגדר המשתנה `BASE_URL`. שנו אותו כך שיצביע לכתובת ה-IP של המחשב שלכם. 
לדוגמה, אם ה-IP שלכם הוא `192.168.1.15`, הקוד צריך להיראות כך:
   ```javascript
   let BASE_URL = 'http://192.168.1.15:1234'; // שנו לכתובת שלכם
   // אם יש תנאים של אנדרואיד/iOS, תוכלו פשוט למחוק אותם או לעדכן את כולם
   ```
4. שמרו את הקובץ, ושרת ה-Expo יתרפרש אוטומטית במכשיר הנייד. כעת האפליקציה תצליח לתקשר עם השרת!
